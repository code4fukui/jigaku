# jigaku

Jigakuは、小学生の自学をサポートするために設計された、シンプルで無料、かつ広告なしのWebアプリケーションシリーズです。

**[▶ ライブデモを試す！](https://code4fukui.github.io/jigaku/)**

## 学習モジュール

このスイートには、国語と算数の基本概念を練習するための、フルスクリーンでインタラクティブなアプリが含まれています。

| モジュール | 科目 | 対象学年 |
| --- | --- | --- |
| [ひらがなとカタカナ](https://code4fukui.github.io/jigaku/hirakata.html) | 国語 | 小学1年 |
| [カタカナとひらがな](https://code4fukui.github.io/jigaku/katahira.html) | 国語 | 小学1年 |
| [かなとローマ字](https://code4fukui.github.io/jigaku/kanaroma.html) | 国語 | 小学3年 |
| [ローマ字とかな](https://code4fukui.github.io/jigaku/romakana.html) | 国語 | 小学3年 |
| [読みやすい時計](https://code4fukui.github.io/jigaku/clock.html) | 算数 | 小学1年～3年 |
| [たして10](https://code4fukui.github.io/jigaku/added10.html) | 算数 | 小学1年 |
| [分数表現](https://code4fukui.github.io/jigaku/frac.html) | 算数 | 小学2年～6年 |
| [単位換算](https://code4fukui.github.io/jigaku/unitcalc.html) | 算数 | 小学2年～6年 |

## 使い方

インストールは不要です。最新のWebブラウザで[Jigakuのデモページ](https://code4fukui.github.io/jigaku/)を開き、学習モジュールを選択するだけです。アプリはiPadなどのタブレットでの使用を想定して設計されていますが、ブラウザを搭載したあらゆるデバイスで動作します。

## オープンデータ

教材およびアプリケーションのリストは、以下の形式でオープンデータとして利用可能です。

- [CSV](https://code4fukui.github.io/jigaku/index.csv)
- [JSON](https://code4fukui.github.io/jigaku/index.json)
- [HTML（Microdata付き）](https://code4fukui.github.io/jigaku/index.html)
