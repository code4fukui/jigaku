# jigaku

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

Jigaku is a series of simple, free, and ad-free web applications designed to support self-learning for elementary school students.

**[▶ Try the live demo!](https://code4fukui.github.io/jigaku/)**

## Learning Modules

The suite includes full-screen, interactive apps for practicing fundamental concepts in Japanese and Math.

| Module                                                                 | Subject  | Target Grade(s) |
| ---------------------------------------------------------------------- | -------- | --------------- |
| [Hiragana and Katakana](https://code4fukui.github.io/jigaku/hirakata.html) | Japanese | 1st             |
| [Katakana and Hiragana](https://code4fukui.github.io/jigaku/katahira.html) | Japanese | 1st             |
| [Kana and Romaji](https://code4fukui.github.io/jigaku/kanaroma.html)       | Japanese | 3rd             |
| [Romaji and Kana](https://code4fukui.github.io/jigaku/romakana.html)       | Japanese | 3rd             |
| [Easy-to-read Clock](https://code4fukui.github.io/jigaku/clock.html)       | Math     | 1st - 3rd       |
| [Add to 10](https://code4fukui.github.io/jigaku/added10.html)              | Math     | 1st             |
| [Fraction Representation](https://code4fukui.github.io/jigaku/frac.html)   | Math     | 2nd - 6th       |
| [Unit Calculator](https://code4fukui.github.io/jigaku/unitcalc.html)       | Math     | 2nd - 6th       |

## Usage

No installation is required. Simply open the [Jigaku demo page](https://code4fukui.github.io/jigaku/) in any modern web browser and select a learning module. The apps are designed to be used on tablets like iPads but work on any device with a browser.
